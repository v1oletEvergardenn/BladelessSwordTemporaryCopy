# Dialogue System Player Sequence Commands Cheat Sheet

This project supports custom player commands for Dialogue System sequences.

---

## Quick Start

### Recommended cutscene pattern
1. Use `PClearInput()` before scripted player actions.
2. Chain commands with `->Message(...)` and `@Message(...)` for deterministic order.
3. Mark important cleanup/restore commands as `required` when needed.

---

## Command Reference

## 1) `PAttack(...)`
Forces normal player attack.

### Signature
`PAttack([left|right])`

### Parameters
- `left|right` (optional):
  - attack direction.
  - default: `right`.

### Notes
- Forced mode: ignores normal gameplay gating/cooldown/energy checks.

### Examples
- `PAttack()`
- `PAttack(left)`
- `PAttack(right)`

---

## 2) `PAttackHS(...)`
Forces Heart Sword **CounterAttack only**.

### Signature
`PAttackHS([left|right])`

### Parameters
- `left|right` (optional):
  - attack direction for HS CounterAttack.
  - default: `right`.

### Notes
- This command is hard-bound to `HS_CounterAttack`.
- It does **not** use current activated HS ability.

### Examples
- `PAttackHS()`
- `PAttackHS(left)`
- `PAttackHS(right)`

---

## 3) `PHS(...)`
Forces a specific named Heart Sword ability.

### Signature
`PHS(left|right, abilityName)`

### Parameters
- `left|right` (required):
  - attack direction context passed to the ability.
- `abilityName` (required):
  - name of HS ability to force.
  - supported:
    - `CounterAttack` (aliases: `counter`, `hs_counterattack`)
    - `CriticalSlash` (aliases: `critical`, `hs_criticalslash`)
    - `SlashWave` (aliases: `wave`, `hs_slashwave`)

### Examples
- `PHS(left,CounterAttack)`
- `PHS(right,CriticalSlash)`
- `PHS(left,SlashWave)`

---

## 4) `PTeleport(...)`
Forces forward sword teleport.

### Signature
`PTeleport([wait|nowait])`

### Parameters
- `wait|nowait` (optional):
  - `wait`: command blocks until teleport finishes.
  - `nowait`: command continues immediately.
  - default: `wait`.

### Examples
- `PTeleport()`
- `PTeleport(wait)`
- `PTeleport(nowait)`

---

## 5) `PTeleportTo(...)`
Forces designated sword teleport to world point or target.

### Signature
- `PTeleportTo(x,y[,wait|nowait])`
- `PTeleportTo(targetName[,wait|nowait])`

### Parameters
- `x,y`:
  - world-space teleport destination.
- `targetName`:
  - scene object name (or subject name) to use as destination.
- `wait|nowait` (optional):
  - same meaning as `PTeleport`.
  - default: `wait`.

### Examples
- `PTeleportTo(12.5,3.0)`
- `PTeleportTo(12.5,3.0,nowait)`
- `PTeleportTo(BossAnchor)`
- `PTeleportTo(BossAnchor,wait)`

---

## 6) `PMoveTo(...)`
Forced move helper with run/walk/custom speed and optional facing.

### Signature
`PMoveTo(xOrTarget[,keep|left|right][,run|walk|speed][,relative|set])`

### Parameters
- `xOrTarget` (required):
  - number: X movement amount or absolute X (based on space mode).
  - string: target GameObject/subject name (moves to target world X).
- `run|walk|speed` (optional):
  - `run`: use run speed.
  - `walk`: use walk speed.
  - `speed`: custom walking speed (example: `1.8`).
  - default: `run`.
- `keep|left|right` (optional):
  - final facing after movement.
  - default: `keep`.
- `relative|set` (optional):
  - numeric `x` only:
    - `relative`: move by delta X from current position.
    - `set`: move to absolute world X.
  - target name:
    - moves to target world X directly.
  - default: `relative`.

### Behavior
- This command **always waits** until movement is complete.
- No `wait|nowait` parameter.

### Examples
- `PMoveTo(5)`                          // run, keep, relative
- `PMoveTo(5,walk)`                     // walk, keep, relative
- `PMoveTo(14,right,run,set)`           // world X=14
- `PMoveTo(2.5,left,1.8,relative)`      // custom speed
- `PMoveTo(BossMark)`                   // move to BossMark.x
- `PMoveTo("gameobjectName")`           // quoted target form
- `PMoveTo(BossMark,walk,left)`         // target + walk + facing

## 7) `PFace(...)`
Force facing direction or face target.

### Signature
`PFace(left|right|targetName)`

### Parameters
- `left|right`:
  - explicit facing direction.
- `targetName`:
  - face toward target object¡¯s X position.

### Examples
- `PFace(left)`
- `PFace(right)`
- `PFace(Boss)`

## 8) `PStop()`
Stops player movement/run-to-target flow.

### Signature
`PStop()`

### Parameters
- none.

### Examples
- `PStop()`

---

## 9) `PJump()`
Forces jump.

### Signature
`PJump()`

### Parameters
- none.

### Examples
- `PJump()`

---

## 10) `PDoubleJump(...)`
Forces double jump with hold strength.

### Signature
`PDoubleJump([hold=0.2])`

### Parameters
- `hold` (optional):
  - virtual hold time fed into double-jump force scaling.
  - higher value => stronger jump (up to gameplay clamp).
  - default: `0.2`.

### Examples
- `PDoubleJump()`
- `PDoubleJump(0.35)`

---

## 11) `PGravity(...)`
Toggles player gravity.

### Signature
`PGravity(on|off)`

### Parameters
- `on|off` (required):
  - `on` = restore gravity.
  - `off` = disable gravity.

### Examples
- `PGravity(off)`
- `PGravity(on)`

---

## 12) `PClearInput()`
Clears input states and pending attack/floating prep states.

### Signature
`PClearInput()`

### Parameters
- none.

### Examples
- `PClearInput()`

---

## 13) `PMoveState(...)`
Switches movement state machine state.

### Signature
`PMoveState(normal|windwalking|standingontemple)`

### Parameters
- `normal|windwalking|standingontemple` (required):
  - target player movement state.

### Examples
- `PMoveState(normal)`
- `PMoveState(windwalking)`
- `PMoveState(standingontemple)`

---

## 14) `PAnim(...)`
Plays body animator state directly.

### Signature
`PAnim(stateName[,normalizedTime])`

### Parameters
- `stateName` (required):
  - animator state name in body animator.
- `normalizedTime` (optional):
  - start position in animation (`0` to `1`).
  - default: `0`.

### Examples
- `PAnim(idle)`
- `PAnim(attack_idle_1,0.0)`
- `PAnim(tele_pre_idle,0.2)`

---

## 15) `PLegAnim(...)`
Plays leg animator state directly.

### Signature
`PLegAnim(stateName[,normalizedTime])`

### Parameters
- `stateName` (required):
  - animator state name in leg animator.
- `normalizedTime` (optional):
  - start position in animation (`0` to `1`).
  - default: `0`.

### Examples
- `PLegAnim(leg_idle)`
- `PLegAnim(leg_run,0.0)`

---

## Forced Mode Behavior

All player commands are cinematic-authoritative:
- Ignore normal action checks (`CanAttack`, `CanTeleport`, etc.).
- Ignore lock/cooldown/resource gating for command execution.
- Intended for cutscene reliability, not normal gameplay flow.

---

## Sequence Timing Tips

Use message chaining for deterministic behavior:
- `CmdA()->Message(Step1);`
- `CmdB()@Message(Step1)->Message(Step2);`

Use `required` for must-run cleanup/critical steps:
- `required PStop()@Message(StepX);`

## Full Test Sequence (Player Commands)

PClearInput();

PFace(right);
PAnim(idle,0);
PLegAnim(leg_idle,0);

PMoveTo(6,run,right,relative)->Message(P1);
PMoveTo(2,walk,left,relative)@Message(P1)->Message(P2);
PMoveTo(14,1.8,keep,set)@Message(P2)->Message(P3);

PAttack(right)@Message(P3)->Message(P4);
PAttackHS(left)@Message(P4)->Message(P5);

PHS(right,CounterAttack)@Message(P5)->Message(P6);
PHS(left,CriticalSlash)@Message(P6)->Message(P7);
PHS(right,SlashWave)@Message(P7)->Message(P8);

PTeleport(wait)@Message(P8)->Message(P9);
PTeleportTo(Boss,wait)@Message(P9)->Message(P10);

PJump()@Message(P10)->Message(P11);
PDoubleJump(0.25)@Message(P11)->Message(P12);

PGravity(off)@Message(P12)->Message(P13);
PAnim(idle,0)@Message(P13)->Message(P14);
PGravity(on)@Message(P14)->Message(P15);

PMoveState(windwalking)@Message(P15)->Message(P16);
PMoveState(normal)@Message(P16)->Message(P17);

required PStop()@Message(P17);
